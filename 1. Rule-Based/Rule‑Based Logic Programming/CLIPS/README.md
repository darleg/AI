#  CLIPSExplanationRules: The program uses defrule to define rules. Each rule has conditions (patterns) and actions (right-hand side).Facts: Facts are asserted into the knowledge base using assert. For example, (animal-is mammal) is a fact.Inference: The program matches facts against rules and executes the corresponding actions.Interaction: The ask-animal rule prompts the user for input and dynamically asserts a fact based on the response.
